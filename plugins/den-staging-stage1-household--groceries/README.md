# den-staging-stage1-household--groceries

Groceries: One grocery list: add it, tick it when bought, clear it.

This plugin installs two things.

- **The connector**, at `https://den-staging.pkslabs.com/mcp/@stage1-household/groceries`: den's tools, speaking this kind's language. Run `/mcp` in a session to sign in and pick the workspace you share.
- **The skill**, generated from the marketplace listing `groceries` v2.

To remove: `claude plugin uninstall den-staging-stage1-household--groceries@den-staging-pkslabs-com`.
