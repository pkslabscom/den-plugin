# den-staging-reef-walkthrough-71873--my-house

My house: Keeps your groceries list tidy and marks what renews next.

This plugin installs two things.

- **The connector**, at `https://den-staging.pkslabs.com/mcp/@reef-walkthrough-71873/my-house`: den's tools, speaking this kind's language. Run `/mcp` in a session to sign in and pick the workspace you share.
- **The skill**, generated from the marketplace listing `my-house` v21.

To remove: `claude plugin uninstall den-staging-reef-walkthrough-71873--my-house@den-staging-pkslabs-com`.
