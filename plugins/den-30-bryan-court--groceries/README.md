# den-30-bryan-court--groceries

Groceries: A simple grocery list: add, tick, clear.

This plugin installs two things.

- **The connector**, at `https://den.pkslabs.com/mcp/@30-bryan-court/groceries`: den's tools, speaking this kind's language. Run `/mcp` in a session to sign in and pick the workspace you share.
- **The skill**, generated from the marketplace listing `groceries` v1.

To remove: `claude plugin uninstall den-30-bryan-court--groceries@den-pkslabs-com`.
